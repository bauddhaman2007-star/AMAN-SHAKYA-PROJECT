01 · Project overview

About the Super Smart Dustbin

The Super Smart Dustbin is an automated waste-management model designed to improve cleanliness and hygiene. It opens its lid without physical contact, monitors the waste level and alerts users when the bin is nearly full.

Project details

Project type: Working Model
Class: 12 Science Exhibition
Model height: 2 feet (approximately 60 cm)
Technology: Arduino, ultrasonic sensors, servo motor and LCD
Estimated budget: ₹1,000–₹2,000

03 · How it works

Working Principle

Two HC-SR04 ultrasonic sensors perform different jobs. The Arduino processes their readings and controls the output devices.

Sensor 1 — Hand Detection

Mounted near the front/top. It detects a hand within the selected range and signals the Arduino to open the lid using the servo motor.

Sensor 2 — Waste Level Detection

Mounted under the lid and facing downward. It measures the distance from the sensor to the waste surface. A shorter distance means the bin is fuller.

Percentage calculation: Fill % = ((Empty-bin distance − Measured distance) ÷ (Empty-bin distance − Full-bin distance)) × 100. Calibrate the empty and full distances for your actual bin.

System sequence

Hand detected → Arduino commands servo → Lid opens → Hand moves away → Lid closes. At the same time, waste sensor measures fill level → LCD updates → At 80% or more, buzzer and red LED turn on.

Important power safety

  • Power the servo from a separate regulated 5V supply rated for its current.
  • Connect the external supply GND to Arduino GND (common ground).
  • Do not power a servo from the Arduino 5V pin if it causes resets or voltage drops.
  • Place the 470µF capacitor across servo supply +5V and GND, observing polarity.
  • Check wiring before switching on power.

07 · Programming

Arduino Source Code

Upload this sketch using the Arduino IDE. Install the Servo and LiquidCrystal_I2C libraries. If your LCD backpack uses a different I2C address, change 0x27 to 0x3F (or scan for its address).

super_smart_dustbin.ino
#include <Servo.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Change 0x27 to 0x3F if required by your LCD module.
LiquidCrystal_I2C lcd(0x27, 16, 2);
Servo lidServo;

// Pin connections
const byte HAND_TRIG = 2;
const byte HAND_ECHO = 3;
const byte WASTE_TRIG = 4;
const byte WASTE_ECHO = 5;
const byte SERVO_PIN = 6;
const byte BUZZER_PIN = 7;
const byte GREEN_LED = 8;
const byte RED_LED = 9;

// Calibrate these distances for your dustbin (in centimetres).
const float EMPTY_DISTANCE_CM = 30.0; // sensor-to-bottom when empty
const float FULL_DISTANCE_CM  = 5.0;  // sensor-to-waste when full
const int ALERT_LEVEL = 80;
const int HAND_RANGE_CM = 20;
const int OPEN_ANGLE = 95;
const int CLOSED_ANGLE = 5;

unsigned long lidOpenedAt = 0;
bool lidIsOpen = false;
unsigned long lastWasteRead = 0;
int fillPercent = 0;

float readDistance(byte trigPin, byte echoPin) {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(3);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // Timeout avoids waiting too long when no echo is received.
  unsigned long duration = pulseIn(echoPin, HIGH, 30000UL);
  if (duration == 0) return -1; // invalid reading
  return duration * 0.0343 / 2.0;
}

int calculateFill(float distanceCm) {
  if (distanceCm < 0) return -1;
  float percent = (EMPTY_DISTANCE_CM - distanceCm) *
                  100.0 / (EMPTY_DISTANCE_CM - FULL_DISTANCE_CM);
  return constrain((int)(percent + 0.5), 0, 100);
}

void updateWasteStatus() {
  float distance = readDistance(WASTE_TRIG, WASTE_ECHO);
  int measured = calculateFill(distance);

  if (measured >= 0) fillPercent = measured;

  bool isFull = fillPercent >= ALERT_LEVEL;
  digitalWrite(RED_LED, isFull ? HIGH : LOW);
  digitalWrite(GREEN_LED, isFull ? LOW : HIGH);
  digitalWrite(BUZZER_PIN, isFull ? HIGH : LOW);

  lcd.setCursor(0, 0);
  lcd.print("Waste Level:    ");
  lcd.setCursor(0, 1);
  if (measured < 0) {
    lcd.print("Sensor Error    ");
  } else {
    lcd.print(fillPercent);
    lcd.print("% ");
    lcd.print(isFull ? "BIN FULL! " : "Normal    ");
  }
}

void setup() {
  pinMode(HAND_TRIG, OUTPUT);
  pinMode(HAND_ECHO, INPUT);
  pinMode(WASTE_TRIG, OUTPUT);
  pinMode(WASTE_ECHO, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  pinMode(GREEN_LED, OUTPUT);
  pinMode(RED_LED, OUTPUT);

  digitalWrite(BUZZER_PIN, LOW);
  lidServo.attach(SERVO_PIN);
  lidServo.write(CLOSED_ANGLE);

  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("SMART DUSTBIN");
  lcd.setCursor(0, 1);
  lcd.print("By Aman Bauddha");
  delay(1800);
  lcd.clear();
}

void loop() {
  // Read the hand sensor and open lid when a hand is nearby.
  float handDistance = readDistance(HAND_TRIG, HAND_ECHO);
  if (handDistance > 0 && handDistance <= HAND_RANGE_CM) {
    lidServo.write(OPEN_ANGLE);
    lidOpenedAt = millis();
    lidIsOpen = true;
  }

  // Close lid 2 seconds after the last hand detection.
  if (lidIsOpen && millis() - lidOpenedAt >= 2000UL) {
    lidServo.write(CLOSED_ANGLE);
    lidIsOpen = false;
  }

  // Update waste level about twice per second.
  if (millis() - lastWasteRead >= 500UL) {
    lastWasteRead = millis();
    updateWasteStatus();
  }

  delay(60);
}
Calibration: Measure the sensor-to-bottom distance with the bin empty and the sensor-to-waste distance at the level you consider full. Update EMPTY_DISTANCE_CM and FULL_DISTANCE_CM. Test the servo angles with the lid disconnected first. A continuous buzzer at 80% is used in this basic example; add timed beeping if preferred.

Today, I am presenting my project, Super Smart Dustbin.

The main objective of this project is to promote hygiene and improve waste management through automation.

This model uses an Arduino microcontroller, ultrasonic sensors, a servo motor and an LCD display.

14 · Judge's questions

Frequently Asked Questions (Viva)

Q1. What is Arduino?

Arduino is a programmable microcontroller development board used to control electronic components.

Q2. What is an ultrasonic sensor?

It measures distance using high-frequency sound waves and the time taken for the echo to return.

Q3. Why are two ultrasonic sensors used?

One detects a nearby hand; the other measures the waste level inside the bin.

Q4. What is the function of the servo motor?

It moves the lid to open and close it automatically.

Q5. Why is an LCD display used?

It displays the current approximate waste level and system status.

Q6. What happens when the dustbin becomes 80% full?

The buzzer sounds, the red LED turns on and the LCD displays a full-bin warning.

Q7. Where can this technology be used?

Homes, schools, hospitals, offices, shopping centres and public places.

Q8. How is the waste percentage calculated?

The Arduino maps the measured sensor distance between calibrated empty and full distances to a percentage from 0% to 100%.

Q9. Why does the servo need a separate power supply?

A servo can draw more current than the Arduino board can safely provide. A separate regulated supply helps prevent voltage drops and resets. Both grounds must be connected together.

Q10. What is the limitation of this model?

Ultrasonic readings can vary with irregular waste surfaces, soft materials or sensor placement. Calibration and careful mounting improve reliability.
